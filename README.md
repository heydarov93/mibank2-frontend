## Overview

MiBank2 Frontend is a web application built with modern frontend technologies.
It provides a professional banking interface with transaction history, deposits, and account management features.


## Installation & Running Locally
1. Clone the repository
   
```

   git clone https://github.com/heydarov93/mibank2-frontend.git
   cd mibank2-frontend

```

2. Install dependencies

```

npm install

```

3. Start the development server

```

npm start

```
The app will run on http://localhost:3000


4. Run tests (optional)

```

npm test

```

5. Build for production (optional)

```

npm run build

```

## Tech Stack (Frontend)

**React** – UI library

**RTK Query (Redux Toolkit)** – Data fetching and caching

**Material UI (MUI)** – UI components and styling

**React Hook Form + Yup** – Forms and validation

**Jest & React Testing Library** – Testing

**React i18n (i18next)** – Multi-language support

**TypeScript** – Type safety

**Prettier & ESLint** – Code formatting and linting
